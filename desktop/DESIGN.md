# Mini-ima 桌面参考图 UI

本轮按用户提供的参考图重做桌面视觉，保留 Tauri 2、React、TypeScript、现有 Python/C++ 业务和 CLI。设计方向为参考图的淡紫色三栏知识工作台，使用 design-taste-frontend 的排版审查和 image-to-code / design-qa 的截图对照方法。

设计参数：DESIGN_VARIANCE=3、MOTION_INTENSITY=2、VISUAL_DENSITY=6，以参考图本身的结构、轻量反馈和阅读密度为准。

## 布局

- 顶栏 76px，包含书本标识、知识库搜索、设置、外观切换及原生窗口控制。
- 1536 × 1024 对照尺寸中，侧栏位于 x=10，宽 240px；中央工作区位于 x=260，宽约 772px；来源区位于 x=1042，宽约 484px。
- 采用淡紫色选中态、半透明白色面板、12–16px 圆角、细描边和轻量切换动效。
- 默认进入 AI 问答；左侧“AI 问答、全局搜索、知识库”复用原有问答、搜索和文档工作区。
- 回答采用右侧问题气泡、助手图案、编号段落、引用列表与底部输入框。
- 来源采用纸张式阅读面板、相关片段、原文行号和详情切换，数据继续使用实际文档内容。
- 书本标识和助手从用户提供的参考图中提取，其他图标沿用已有 Lucide；外观按钮使用月亮/太阳。

默认 Windows 窗口 1440 × 960，最小 980 × 680。使用自绘标题栏还原参考图；拖动、最小化、最大化/还原和关闭仍调用 Tauri 原生窗口接口。关闭沿用既有任务退出确认，不直接绕过关闭事件销毁窗口。

## 功能保持

知识库管理、TXT/Markdown 导入、重复跳过、检索、真实引用、配置保存与连接测试保持兼容。新增持久对话与回收站，数据库通过增量迁移升级，桌面与 CLI 仍共用 MINIIMA_HOME。

“添加文件”复用原导入流程。醒目的“新建对话”和顶部加号进入空白会话，挂载及抽屉关闭后聚焦输入框；首次发送落库。历史列表按更新时间排序、50 条分页，点击恢复知识库、完整消息与各轮引用。长历史和知识库分别滚动，“最近文档”为折叠分区。

新 Key 默认可见，已有 Key 保持留空，两个隐藏开关独立。齿轮进入设置，右上月亮/太阳切换深浅外观。左上按钮可完整隐藏侧栏并记忆，窄屏保留抽屉导航。

“笔记”和“标签”入口移除；“回收站”可恢复知识库和对话，并为彻底删除、清空提供确认。联网搜索和深度思考继续禁用。来源显示实际支持的 Markdown / 文本及行号，不伪装成 PDF 页码，不写入示例知识库。

## 验证

视觉验收见 design-qa.md，截图及尺寸记录位于 build/reference-review/。本轮使用显式 Mock 预览进行截图对照，正式程序不启用示例数据。

当前持久对话、回收站和侧栏改造的自动及 Windows 验收结果以 VERIFICATION.md 为准。开发预览排除构建目录监听，避免打包触发输入丢失；预览数据只保存在浏览器本地，正式数据保存在 SQLite。真实 API 仍由用户在设置页测试。
