# 计算机网络笔记

## TCP 三次握手

TCP 用三次握手建立连接。客户端发送 SYN，服务器回复 SYN 与 ACK，客户端再发送 ACK。双方在这个过程中确认彼此的发送、接收能力，并交换初始序列号。

第三次握手让服务器确认客户端已收到服务器的初始序列号，也帮助避免旧的连接请求造成错误连接。

## 以太网最短帧长

共享介质的半双工以太网使用 CSMA/CD 检测冲突。发送方在最远端发生冲突的信号返回之前，应仍在发送帧。因此帧的发送时间需要覆盖网络的最大往返传播时延。

传统以太网规定最短帧长为 64 字节（从目的 MAC 地址到 FCS），不包含前导码和帧起始定界符。现代交换式全双工以太网不使用 CSMA/CD。
